# OpenFactor. RFC 9116.
#
# In order of preference, which is what RFC 9116 says this ordering means.
#
# The advisory channel is first because it is private: a report there is not readable by anybody
# until it is resolved. The address is second because it needs no account, and a researcher
# without a GitHub login previously had no way to reach this project at all. Email is not
# encrypted, so it is the right place to say you have found something and the wrong place to
# describe it.
#
# **security@ rather than info@, which this file named until 2026-08-22.** RFC 2142 defines
# security@ for exactly this, so it is the address a researcher guesses before reading anything.
# A file whose purpose is to remove the guessing should not point away from it. Both forward to
# the same place, so nothing about who reads it has changed.
